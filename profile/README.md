<p>"代理IP"和"住宅IP"这两个词在市场上经常被混着用，很多新手以为是一回事，买完才发现拿到的是机房段。其实两者是包含关系：代理IP是统称，住宅IP是其中门槛最高的一类。搞清楚区别，是买对产品的第一步。</p>

<h2>一、概念先厘清：代理IP是大类，住宅IP是其中一类</h2>

<p>所有通过中间服务器转发流量的出口，都可以叫代理IP。按出口性质分，常见三类：机房代理（数据中心）、住宅代理（家庭宽带）、移动代理（蜂窝网络）。住宅IP指的是 ASN 归属本地电信、广电、宽带运营商的地址段——它的"户口"在居民宽带里，而不是机房里。</p>

<p>市场上还有个容易混淆的说法："住宅代理IP"通常指可以轮换的住宅IP池，强调换着用；"静态住宅IP"强调固定一个地址长期用。买的时候先确认自己要的是池子还是钉子。</p>

<h2>三、风控系统是怎么看出来的</h2>

<p>平台判断一个地址可不可疑，主要靠三样东西：公开的代理与黑名单情报库、IP 的 whois 与 ASN 注册信息、以及这个地址的历史行为记录。机房段因为被大量用于爬虫和批量注册，在情报库里几乎都有标记；住宅段分散在真实用户手里，情报干净得多。这不是玄学，是数据库比对。</p>

<h2>四、购买时的三步判断法</h2>

<h3>第一步：查户口</h3>

<p>问服务商要测试IP，先查 whois 的 orgname、netname 和 ASN 归属，看是不是宣称地区的本地运营商。写着美国城市、ASN 却是某云厂商的，就是机房段包装。</p>

<h3>第二步：查案底</h3>

<p>用公开的代理识别库查这个IP有没有 proxy、hosting、VPN 标记。有标记的段，再便宜也别碰，平台风控库和这些识别库很多是通的。</p>

<h3>第三步：实测</h3>

<p>拿测试IP登录你实际要用的平台（风控最严的那个），看有没有异常验证提示。三步都过，再谈付款。</p>

<h2>五、购买前必须问清的四个问题</h2>

<p>1. 是独享还是共享？2. 静态还是可轮换？3. 带宽是单IP独享还是整段共享？4. IP 被平台标记后能不能免费换？四个答案都清晰的服务商，踩坑概率直接降一半。</p>

<h2>六、常见问题</h2>

<h3>住宅代理IP和静态住宅IP选哪个？</h3>

<p>业务是长期账号（店铺、AI订阅、社媒），选静态；任务是短时高频、需要大量不同出口的公开数据采集，选可轮换的住宅代理。预算允许就静态为主、池子补充。</p>

<h3>机房IP真的一点都不能用吗？</h3>

<p>也不是。爬取公开数据、测试、学习用途，机房代理性价比高。但只要涉及账号登录和平台业务，就别拿机房段去试。</p>

<h3>为什么同类型产品价格差好几倍？</h3>

<p>段源不同。真家宽段、广播段、机房伪装段，成本差着量级，售价自然分开。低于市场价下限的，先怀疑段源。</p>
